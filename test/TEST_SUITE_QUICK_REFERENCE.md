## File API Reference

### `extract_bayer_layers(bayer_array) → dict`
Extract BGGR pattern into separate layers.

```python
from test.test_bayer_display import extract_bayer_layers
import numpy as np

bayer = np.load("mock_camera/cfg5_sbggr1_raw_00.npy")
layers = extract_bayer_layers(bayer)

# Access layers
blue_layer = layers['B']    # (616, 820)
green_layer = layers['Gb']  # (616, 820)
red_layer = layers['R']     # (616, 820)
```

### `plot_bayer_layers(bayer_array, output_file=None) → (fig, axes)`
Display layers in 2×2 subplot grid.

```python
from test.test_bayer_display import plot_bayer_layers
import numpy as np

bayer = np.load("mock_camera/cfg5_sbggr1_raw_00.npy")
fig, axes = plot_bayer_layers(bayer, output_file="output.png")
# Opens matplotlib window, saves PNG if output_file specified
```

### `main() → bool`
Full test execution with file loading and validation.

```python
from test.test_bayer_display import main

success = main()  # Returns True if test passed
```

## Usage Examples

### Example 1: Run Test (Simplest)
```bash
python test/test_bayer_display.py
```

### Example 2: Import in Your Code
```python
import sys
sys.path.insert(0, "test")
from test_bayer_display import extract_bayer_layers, plot_bayer_layers
import numpy as np

bayer = np.load("mock_camera/cfg5_sbggr1_raw_00.npy")
layers = extract_bayer_layers(bayer)
plot_bayer_layers(bayer, "my_output.png")
```

### Example 3: Programmatic Analysis
```python
from test.test_bayer_display import extract_bayer_layers
import numpy as np

bayer = np.load("mock_camera/cfg5_sbggr1_raw_00.npy")
layers = extract_bayer_layers(bayer)

# Analyze each layer
for name, layer in layers.items():
    print(f"{name}: mean={layer.mean():.1f}, max={layer.max()}")
```

### Example 4: Batch Process All Configs
```python
from test.test_bayer_display import plot_bayer_layers
from pathlib import Path
import numpy as np

mock_dir = Path("mock_camera")
for cfg in [4, 5, 6]:
    npy_file = mock_dir / f"cfg{cfg}_sbggr1_raw_00.npy"
    if npy_file.exists():
        bayer = np.load(npy_file)
        plot_bayer_layers(bayer, f"test/cfg{cfg}_display.png")
```
