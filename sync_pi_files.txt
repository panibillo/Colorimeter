# sync_pi_files.txt — explicit list of files mirrored onto the Pi.
#
# Used by sync_to_pi.sh, which rsyncs each listed path from
# ~/Projects/Colorimeter/ to ~/pi/Colorimeter/ on the remote.
#
# Rules:
#   - Paths are relative to the project root.
#   - Wildcards are NOT expanded. rsync --files-from takes literal paths, so
#     every file must be listed individually. Adding a module to the project
#     means adding a line here too, or it silently never reaches the Pi.
#   - Comments and blank lines are stripped by sync_to_pi.sh before the list
#     reaches rsync. rsync itself does NOT treat '#' as a comment in a
#     --files-from file (only in --exclude-from / --include-from / filter
#     files), so this file must not be passed to rsync directly.
#
# The list below is the import graph of the two entry points — src/main.py
# (touchscreen application) and dev/camtest8.py (command-line capture) — plus
# the data files they read. See the end of this file for how to regenerate it.
